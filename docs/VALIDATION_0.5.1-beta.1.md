# Luma 0.5.1-beta.1 validation / 验证记录

Date: 2026-11-04 (Asia/Shanghai). Windows x64, Electron 45.2.1, Python 3.14.6. All desktop/runtime tests use isolated temporary profiles and synthetic media. No test migrates or edits the owner's live library.

- 89 Python tests passed: migration/recovery, source/task preservation, exclusion rules, shared-media account removal and Undo, collection limits/order, language hints, pinned avatars, persistent similarity checkpoints/ignored groups, cancellation and safe handover while RPC readers remain active.
- 30 Node tests passed: loopback authentication and opt-in listener, origin/rebinding rejection, request limits, token rotation, completion actions, profiles, X cookie scope/identity, workspace persistence, physical-path alias deduplication and browser capture.
- Production TypeScript/Vite build passed. Translation coverage and numbered placeholders validated for the Chinese/English UI and native menus.
- Desktop integration passed: three collection selectors and inline creation, reusable notes, editable flags, drag ordering, stable avatar through library revisions, history dialog, original post dates, internal account context menu, guarded account removal, sticky actions at 1050×670, English reload and four alternating library switches with persisted selection.
- Twelve image/H.264-video preview cases passed at 1280×800, 1920×1080, 3840×2160 and 1000×640, including 200% UI scale, 160% text size, fit/100%/zoom/scroll behavior and toolbar separation. The old MPEG-4 Part 2 fixture is replaced by a synthetic H.264 fixture; the development encoder is excluded from public binaries.
- Desktop integration also passed with a junction-alias temporary directory, reproducing the long/short path mismatch found on the clean Windows runner. Existing duplicate workspace IDs retain the first ID and manual appearance, keep alias-ID lookups and save a registry backup before merging.
- Synthetic large-library benchmark passed six alternating switches with 61,000 media rows and 285 paused tasks. Handover measurements were 22–75 ms in this environment; this does not measure disk migration, network storage, antivirus delays or the complete renderer reload.
- Frozen core passed local OCR, existing pinned Chinese-CLIP model indexing/search and independent FFmpeg video import. Frozen collector loaded its actual pinned engine, downloaded one loopback image, skipped known/deleted items and preserved original post metadata. Assistant plan/apply/Undo/edit-version flows and a real following subprocess lifecycle passed through a loopback deny proxy.
- Actual unpacked and portable executables started with isolated profiles and passed authenticated HTTP/backend checks. Public distribution uses independent core/collector programs, LGPL-configured FFmpeg and original dependency notices. Sources are selected by an explicit whitelist and checked for private paths/credentials.
- `npm audit --omit=dev` reported zero known issues on this date. The full dependency audit still has moderate build-tool advisories; this command does not audit every binary shipped by Electron/Python, and no blanket security guarantee is made.

Live X following imports, protected-account capture, rate limits and long-running collection have not received broad live-account acceptance testing. Capturing real accounts requires the user's valid session and granted access. No cloud image generation, nudity classifier, NAS deployment or automatic shutdown was executed during verification. The beta is unsigned and needs wider cross-machine testing.
