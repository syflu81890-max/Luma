# 安全问题与支持范围

This is a Windows public beta; support focuses on the latest public release. Do not post cookies, session directories, assistant tokens, private databases or photos. If private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise open a non-sensitive Issue asking for a private reporting channel, without exploit details or private data.

Include the app/OS versions, a minimal reproduction, expected/actual behavior and synthetic test data. Remove Authorization values and other credentials. Ordinary feature requests and bugs belong in public Issues.

当前版本为 Windows 预发布版，优先处理最新公开版本中的问题。请勿公开提交 Cookie、登录会话目录、本机助手密钥、个人数据库或照片。

如仓库启用了 GitHub 私密漏洞报告，请在 Security → Report a vulnerability 中报告可复现的安全问题。尚未开启时，先提交不含利用细节和私密数据的 Issue，请求私密沟通渠道。

报告时提供版本、操作系统、最小复现、预期与实际行为；使用合成媒体和临时资料库。涉及接口时去掉 Authorization 值。公开 Issue 适合普通功能缺陷和建议。
