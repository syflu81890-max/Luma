# Luma · 本地媒体资料库

[English](README.md) · [下载](https://github.com/syflu81890-max/Luma/releases) · [反馈问题与建议](https://github.com/syflu81890-max/Luma/issues/new/choose)

**0.5.1-beta.2 公开测试版，适用于 Windows 10/11 x64。** 便携 EXE 双击运行，Setup EXE 支持安装。当前未做代码签名；每次发行同时提供源码、第三方源码和 SHA-256 校验文件。

## 主要功能

- 采集你有权访问的 X 图片、视频、GIF，保存原帖文字、发布时间和来源链接。支持预览、增量采集、定时更新和删除排除。
- 收集账号卡片、评分、私人别名、快捷备注、可编辑地区旗帜，以及最多三个合集。合集支持拖动排序，头像固定显示，昵称和头像历史单独查看。
- 相册、标签、保存筛选、鼠标框选、跨页选择、跟随滚动的批量操作栏和可恢复回收站。
- 相似图片记住已扫描结果，支持增量及指定范围检查、忽略相似组，以及保留高分辨率副本的可预览整理方案。
- 可选本地 Chinese-CLIP 语义找图与 OCR。模型另行下载，推理在本机运行。
- 独立资料库切换，保留账号和任务；可选择启用带密钥的本机助手接口。
- 使用你在本机登录的 X 会话；常规采集无法读取、但你有访问权限的私密账号可尝试浏览器补采。

## 使用与升级

选择资料库位置，在软件内登录 X，再添加账号或支持的网址。首次采集需要从官方 PyPI 下载约 1.4 MB 的固定版本组件并校验哈希，此后使用本机缓存；用户无需安装 Python。先用少量内容确认效果，再执行大任务。

升级前请完全退出旧版，并备份整个资料库。数据库升级会自动备份数据库，完整备份还应包含媒体。本版修复切换资料库后界面锁死的问题，增加阶段进度和取消入口；切换失败保留原库指向。

## 已知范围

真实账号的关注列表与私密采集仍需要更多联网验收；会受到登录权限和 X 限流影响。视频播放取决于 Chromium 支持的编码，不支持的格式可能可以导入封面，但需要外部播放器查看。按语言推测地区只作为可修改建议，不等于确认国籍。相似判断和 OCR 可能出错，请预览删除方案。自动裸露分类、NAS 服务端、网盘备份和图片式主题包暂未实现，仅保留主题扩展接口。

默认不启用遥测或云端推理。公开源码不包含个人图库、账号清单、Cookie、密钥和模型缓存。助手接口默认关闭，只监听本机并要求密钥。详见 [隐私说明](docs/PRIVACY.md)。
